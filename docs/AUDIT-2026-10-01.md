# GrantArena follow-up audit — 2026-10-01

Historical v1 audit. For the current v2 contract and reviewer-gated payout flow, see [the 2026-10-03 verification record](TESTING.md) and [security boundary](SECURITY-V2-ARCHITECTURE.md).

Scope: deployed StudioNet contract, client write/finality path, read-only API, browser form boundaries, funding accounting, production deployment, and known failure patterns from earlier GenLayer builds. This is an engineering audit, not a formal third-party security certification.

## Findings and disposition

| Severity | Finding | Disposition |
| --- | --- | --- |
| High | Finalized StudioNet rollbacks lack `txExecutionResultName` in the JS SDK result, so the UI could claim success for a failed write. Reproduced against a successful and a rolled-back hosted transaction. | Fixed: require `consensus_data.leader_receipt[0].execution_result === SUCCESS`, sender, recipient, and final status. Regression tests added. |
| Medium | A transient StudioNet 502 after submission could be shown as an unlinked failure even if the transaction later finalized. | Fixed with bounded read retries and a persistent transaction link in the notice. |
| Medium | Wallet account/network changes could leave the old account displayed. | Fixed with provider listeners and cleanup; event tests added. |
| Medium | Chrome with multiple wallet extensions exposed OKX through `window.okxwallet` while `window.ethereum` was absent or conflicted; users could see a false missing-wallet message. | Added EIP-6963 multi-provider discovery, a user-facing wallet picker, and EIP-1193/OKX legacy fallbacks. Chrome showed one OKX choice and opened its real connection prompt. |
| Medium | The UI described a queued withdrawal as completed recipient payment. | Fixed the message; verified one external 0.001 test-GEN credit to the owner wallet after cancellation and withdrawal. |
| Medium | Website listed only the first 20 rounds; after round 20, new rounds would disappear from view. | Fixed with newest-page loading and older-page navigation. |
| Medium | If the most recent round was cancelled, Apply displayed an open option but had no selected round or answer fields. | Fixed round selection fallback and reset answers when switching rounds. |
| Medium | The responsive stylesheet hid every navigation action on phones, making the agent panel inaccessible. | Fixed with a compact second-row mobile navigation. |
| Low | Cancelled rounds still advertised an active prize and an Apply invitation. | Fixed status-aware copy, timeline, and empty state. |
| Low | The UI offered “Withdraw credited funds” to any connected wallet, even when its claimable balance was zero. | Fixed by reading `get_claimable` for the connected account and showing withdrawal only for a positive finalized credit. Checked on a newly connected OKX account. |
| Low | Preview API trusted Content-Length and could accept an oversized chunked body. | Fixed with streaming byte limit and a regression test. |
| Low | Non-ASCII/control text could pass the browser forms but be rejected after wallet signing. | Added preflight checks matching contract text bounds. |
| Low | A Git-ignored canary key was stored locally for recovery, but Git ignore alone was not an explicit Vercel upload boundary. | Added `.vercelignore` to exclude `.env*` and all test-only Python assets from deployment uploads. |
| Low | Public-facing wording overstated GitHub availability, semantic novelty checks, and evidence verification. | Corrected website and documentation. |

## Remaining limits

- The user approved a real OKX Wallet connection, but no user-wallet-signed contract transaction was attempted. Bonds remain direct-test/simulator coverage rather than live funded evidence.
- A parent finalized withdrawal record is not proof of external credit in every case; verify recipient balance or child transfer. The canary confirms one instance.
- Applicant evidence URLs are references only, not fetched or authenticated.
- StudioNet is a developer network, not mainnet; its RPC briefly returned HTTP 502 during receipt polling.
