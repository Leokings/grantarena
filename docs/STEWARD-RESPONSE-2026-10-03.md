# GrantArena response to steward feedback

The feedback said unauthenticated award evidence and unresolved adversarial limits required conservative scoring. V2 addresses both without claiming that an AI model can prove real-world grant claims.

1. **Award evidence is independently reproducible.** The [v2 verifier](../scripts/verify-studionet-v2.mjs) reads nine finalized StudioNet transactions, checks successful execution and signer/contract addresses, checks deployed source equality, reads the current contract round/proposal/accounting state, inspects the external transfer instruction, and checks the winner's current balance. It covers both an [attested paid award](STUDIONET-ATTESTED-AWARD-EVIDENCE-2026-10-03.json) and an [unattested unpaid qualified proposal](STUDIONET-UNATTESTED-EVIDENCE-2026-10-03.json). It does not trust success flags in the JSON evidence files.
2. **Unverified applicant claims cannot automatically trigger a funded payout.** The funder names a reviewer wallet distinct from the funder and applicants. A funded applicant supplies at least one reference; only the named reviewer can attest to the exact SHA-256 digest of the proposal version. A contest clears any old attestation. The reviewer may revoke. Qualified but unattested proposals receive zero award and the unused pool returns to the creator.
3. **Simple adversarial inputs face deterministic limits.** Untrusted rubric/proposal content is JSON-serialized into the model prompt and explicitly treated as data; URLs are never described as authenticated. Empty and repeated-filler answers have low caps based on word and distinct-word counts. A contest must contain a material quantity and fraction of new tokens. The stored explanation is constructed from accepted grades, not unchecked model prose. Direct tests cover padding, malformed model output, old-digest reuse, unauthorized reviewer, revocation, contest reset, and no-attestation settlement.

The remaining boundary is explicit: a signature proves which wallet attested, not that a human reviewer is independent or honest; a URL does not prove its contents or authorship; language models can still make mistakes or be influenced by sophisticated attacks. The StudioNet canary wallets were all controlled by the same test operator, so they demonstrate mechanics, not an independent real-world review. GrantArena is not certified for mainnet custody.

After a follow-up audit, the UI now labels the numeric result as an AI rubric score and explicitly says a funded proposal can be `QUALIFIED` without verified evidence or payout eligibility. The funded-round form rejects the unusable zero reviewer address before any wallet request and explains that review should finish by the appeal deadline. A [zero-pool public practice round](STUDIONET-PRACTICE-ROUND-2026-10-03.json) remains open so first-time applicants can try the signed submission flow without implying an award. This is not a new claim of independent human review or guaranteed adversarial robustness.
